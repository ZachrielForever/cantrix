# cantrix

A live-coding music environment for the terminal, written in Python.

Patterns are written as plain text and evaluated live. Loops keep playing while you edit them.

## Status

Early development. See [ROADMAP.md](ROADMAP.md).

## Requirements

- Python 3.11+
- Linux (audio via PortAudio / ALSA)

## Install

Not yet installable. Clone and run from source once the scheduler is up.
